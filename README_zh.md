## 💡 贡献：创建新挑战的指南与提示

### 1. 了解 SE-2 扩展

前往 [SE-2 扩展文档](https://docs.scaffoldeth.io/extensions/createExtensions)，观看视频并阅读概述，熟悉扩展的工作方式。

### 2. 按照步骤创建扩展

1. 克隆 [create-eth 仓库](https://github.com/scaffold-eth/create-eth)，并 cd 进入该目录。

```bash
    git clone https://github.com/scaffold-eth/create-eth
    cd create-eth
```

#### 在 externalExtensions 中进行设置：

2. cd 进入 `externalExtensions`（如果该目录不存在，执行 `mkdir externalExtensions && cd externalExtensions`）

3. 在 `externalExtensions` 中克隆 base-challenge-template，并以你的扩展名称命名：

```bash
    git clone -b base-challenge-template https://github.com/scaffold-eth/se-2-challenges.git <my-challenge-name>
```

4. cd 进入 `<my-challenge-name>` 目录，并以你的挑战名称创建一个分支。

```bash
    cd <my-challenge-name> && git switch -c <my-challenge-name>
```

5. 找到所有标有 `// CHALLENGE-TODO:` 的文件注释，按照其中的说明准备你的挑战。

6. 把这些改动作为初始提交进行提交：`git add . && git commit -m "fill template"`。

#### 需要在 create-eth 仓库中运行的命令：

1. 构建 create-eth cli

```bash
    yarn build:dev
```

2. 创建一个实例，其名称与你在 `externalExtensions` 中创建的挑战目录名称相同：

```bash
    yarn cli ../<my-challenge-name> -e <my-challenge-name> --dev
```

3. 这会在 create-eth 仓库之外创建一个名为 <my-challenge-name> 的完整实例

4. 在该实例中尽情修改，添加你的挑战会用到的所有新文件，然后提交这些改动

5. 在 create-eth 中运行以下命令，把所有改动复制到你的扩展中：

```bash
    yarn create-extension ../<my-challenge-name>
```

### 3. 测试你的扩展

运行 `create-extension` 命令后，你应该能在终端中看到所有已创建的文件以及所有缺失的模板文件。补上缺失的模板文件，然后继续按照[本地测试](https://docs.scaffoldeth.io/extensions/createExtensions#local-testing)一节中的说明进行操作！

别忘了在扩展的顶层添加一个 README.md。它的内容应与你在 `extension/README.md.args.mjs` 的 `extraContents` 变量中填写的内容一致。

根据需要反复迭代、重复上述步骤，直到一切恰到好处。

### 4. 提交 PR

当你把挑战打磨到完美之后，可以请维护者为你的挑战添加一个分支，然后向该分支提交 pull request。由于我们会对这些挑战进行大量测试，请做好经过几轮修改的准备。
