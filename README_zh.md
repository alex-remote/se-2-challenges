# 基础挑战扩展模板
> ⚠️ 这套文件本身并不是用来直接作为扩展使用的。请按照[这里](https://github.com/scaffold-eth/se-2-challenges/blob/main/README.md#-contributing-guide-and-hints-to-create-new-challenges)的说明了解如何使用这套文件。

你可以用这些文件来帮助搭建一个新的扩展，使其与 [Speedrun Ethereum](https://speedrunethereum.com/) 的风格和体验保持一致。

文件中各处放置了 `// CHALLENGE-TODO:` 注释，说明了要让这个模板适用于新挑战需要做哪些关键修改。
